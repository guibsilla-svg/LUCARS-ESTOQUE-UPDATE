# LUCARS ESTOQUE — Atualizações

Este repositório público distribui exclusivamente versões instaláveis do aplicativo LUCARS ESTOQUE. O código-fonte permanece no repositório privado de desenvolvimento.

O aplicativo consulta o arquivo [update.json](https://raw.githubusercontent.com/guibsilla-svg/LUCARS-ESTOQUE-UPDATE/main/update.json) ao iniciar e informa quando há uma versão mais recente.

## Instalação
Baixe o APK publicado na seção [Releases](https://github.com/guibsilla-svg/LUCARS-ESTOQUE-UPDATE/releases).

## Integridade e segurança
- Nunca publique chaves de assinatura ou tokens neste repositório.
- As atualizações precisam usar o mesmo certificado de assinatura da versão instalada.
- O Android sempre solicita confirmação para instalar uma atualização.
